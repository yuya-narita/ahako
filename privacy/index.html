プライバシーポリシー

あ箱は、Scene作品を制作・配布・閲覧する仕組みと、Web文章をScene形式で読む「あ箱 Reader β」を提供します。

1. Readerが扱う情報

ユーザーが「あ箱で読む」を実行したページについて、本文、作品名・タイトル、作者情報、ページURLをReaderが一時的に扱う場合があります。これらは文章抽出、Scene化、表紙表示、作者版の確認などReaderの機能を提供するために使用します。

2. 本文の処理

本文のScene分割はブラウザ内で行います。本文、作品名、作者名を利用統計として外部サーバーへ送信することはありません。

Readerを開くために一時的に保存した本文データは、Readerが読み込んだ後にローカルの一時保存領域から削除します。

3. 通信ONの場合

初回利用時にネットワーク通信を使用するか選択できます。通信をONにした場合、以下の通信をHTTPSで行います。

  • 作者版の確認：現在の記事に作者が公開した「あ箱」版が存在するか照合するため、記事URLをあ箱のAPIへ送信します。照合目的以外には使用しません。
  • 匿名の利用統計：Readerのバージョン、読み込み方法、生成Scene数、Scene進行、読了、作者版の検出数、Reader内の導線利用などを送信する場合があります。

利用統計には、記事URL、ドメイン、URLパス、本文、作品名、作者名を含めません。

4. 通信OFFの場合

通信をOFFにしてもReaderの文章抽出・Scene化・閲覧機能は利用できます。作者版の自動確認と匿名利用統計の送信は停止します。設定はReader内の「DATA」から変更できます。

5. Distribution.scene の匿名観測

配布用の Distribution.scene を対応Playerで開いた場合、作品がどの程度読まれているかを作者・運営者が把握するため、匿名の読書観測を行う場合があります。この観測はDistribution.sceneの閲覧機能の一部として動作し、個別の同意ダイアログは表示しません。

観測時に送信する情報は、作品ID（workId）、配布された一冊を識別するcopyId、当該copyId専用の匿名observerId、閲覧セッションを識別するsessionId、Scene数、現在のScene位置、開始・進行・読了のイベントです。

氏名、メールアドレス、購入者情報、注文情報、アカウントID、ファイル名、ファイルの保存場所、作品本文、作品タイトル、作者名は、この匿名観測データとして送信しません。

observerIdはcopyIdごとにブラウザ内で生成・保存し、異なるcopyId間で共通の利用者識別子として使用しません。観測値は「同じ人物」を厳密に数えるものではなく、同一人物の複数端末・ブラウザ等を別の観測として含む場合があります。また、通信できない環境での閲覧は観測されません。

この観測データは、作品の閲覧状況・読了状況・配布された一冊の広がりを把握し、あ箱の運用・改善および作者向け集計に利用します。購入者の特定、広告配信、行動ターゲティング、信用判断を目的として利用しません。

6. ローカル設定

表示設定や通信設定などReaderの動作に必要な設定をChromeのローカルストレージに保存する場合があります。

7. データの販売・広告利用

Readerが扱うデータを販売・貸与したり、パーソナライズ広告、リターゲティング広告、信用判断、データブローカー用途に使用したりすることはありません。

8. 第三者への提供

Readerの機能提供に必要な場合、法令への対応が必要な場合、またはセキュリティ上必要な場合を除き、ユーザーデータを第三者へ販売または提供しません。

9. セキュリティ

Readerからあ箱のAPIへの通信にはHTTPSを使用します。拡張機能は現在の機能に必要な範囲のChrome権限のみを使用する方針です。

10. Chrome Web Store Limited Use

本拡張機能によるユーザーデータの利用は、Chrome Web Store User Data Policy（Limited Use要件を含む）に従います。取得した情報は、Readerの単一目的である「Web文章をScene形式で読む体験の提供」と、それに必要な機能・運用のためにのみ使用します。

11. ポリシーの変更

Readerのデータ取扱いを変更する場合は本ページを更新し、必要に応じてReader内またはChrome Web Store上で利用者に分かる形で告知します。
