# あ箱 デモサイト

モック画像をもとにした、依存ライブラリなしの静的デモサイトです。

## 使い方
- `index.html` をブラウザで開けばローカルでも動作します。
- GitHub Pages / Cloudflare Pages / Netlify などの静的ホスティングへ、そのまま配置できます。
- `styles.css` と `app.js` 以外の外部依存はありません。

## 実装済み
- レスポンシブLP
- スマホ風のインタラクティブ「あ箱」ミニデモ
- 物語 / 手紙 / 展示ガイド / ショールーム / クイズ / 瞑想 / ホラーの7デモ
- `stack` と `solo` の違いを簡易再現
- 企業活用フロー
- モバイルメニュー

## 本番化時に差し替える場所
- `mailto:hello@example.com` を実際の問い合わせ先へ変更
- 各「デモを体験」ボタンを本物の `.scene` / 公開URLへ接続してもよい
- ロゴや導入事例、アクセス計測を追加
